# Java Calculator

A Java Swing calculator application with a runnable entry point and MySQL connector dependency included in the project folder.

## Structure

- `calculator/` - Java source files in the `calculator` package
- `Main.java` - launches the GUI
- `run.cmd` - convenience script to run the app with the JDBC jar
- `mysql-connector-j-9.3.0.jar` - bundled MySQL connector

## Run

Use the included command:

```bat
run.cmd
```

## Notes

- Compiled `.class` files are ignored by default.
- The project root for a repo should be `D:\Projects\calculator\calculator`.
